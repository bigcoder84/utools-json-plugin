# JSON 序列化（uTools 插件）

一个精简的 uTools JSON 编辑器，在常规 JSON 工具能力之外，增加了**链接快捷跳转、图片悬浮预览、图片提取与定位**。

## 功能

| 功能 | 说明 | 快捷键 |
| --- | --- | --- |
| 格式化 + 语法高亮 | 基于 token 流格式化：保留注释、保留数字原文（大整数不丢精度）、不重排键顺序；自动去掉尾随逗号。粘贴覆盖全文时自动格式化 | `⌘⇧F` / `Alt⇧F` |
| 自动去转义 | 识别 `{\"a\":1}`、`"{\"a\":1}"` 这类转义过的 JSON（最多 3 层），格式化时自动还原 | 随格式化触发 |
| 压缩 | 去除空白、注释和尾随逗号 | `⌘⇧M` |
| 压缩转义并复制 | 压缩后转义为字符串内容（不带首尾引号）并复制到剪贴板 | `⌘⇧E` |
| 折叠 | 工具栏「折叠」折叠到第 2 层（一眼看清结构）、「展开」全部展开；行号旁箭头可逐个折叠 | 光标处折叠/展开 `⌘⌥[` / `⌘⌥]` |
| 成员数提示 | 多行数组的 `[` 后显示「N 项」；折叠后占位符显示 `[… N 项]`、`{… N 个字段}`。提示是纯视觉元素，全选/复制/压缩/转义都不会带上 | — |
| 去除注释 | 去掉 `//` 与 `/* */` 注释，整行注释连同空行一起移除；JSON 不合法时也能用 | — |
| JS 表达式过滤 | 以 `.`、`[`、`?.` 开头时拼接在 `this` 后，如 `.list.map(x => x.id)`；也可写完整表达式，用 `this` / `$` 引用数据，如 `Object.keys($)`。结果只读显示，清空后回到原文（撤销历史、折叠状态都保留） | `⌘E` 聚焦 |
| 嵌套 JSON 字符串 | 内容是 JSON 的字符串值（如 `"text": "{\"code\":...}"`）前面显示「{ } 4 个字段」标签；悬停预览格式化内容，点击标签进入子视图 | — |
| 一键展开嵌套 | 工具栏按钮：把所有层级的嵌套 JSON 字符串递归展开成真实结构（只读），还可以叠加 JS 过滤 | — |
| 链接跳转 | 字符串里的链接显示下划线，`⌘ / Ctrl + 点击` 用系统浏览器打开；悬浮卡片里也有「打开」「复制链接」按钮 | — |
| 图片悬浮预览 | 鼠标悬停在图片链接上显示预览图和尺寸；扩展名不明确的链接不会自动请求，卡片上提供「预览图片」按钮手动加载 | — |
| 图片列表 | 右侧面板列出 JSON 中所有图片，点击定位到字段（折叠中的会自动展开） | `⌘⇧I` |
| 按需多标签 | 默认不显示标签栏；点底部「新增标签页」后出现，可切换、关闭。各标签独立保留内容、撤销历史、折叠、滚动位置及过滤/嵌套视图；只剩一个标签时自动隐藏标签栏 | `⌘T` / `Ctrl+T` |
| 设置 | 底部右侧齿轮：主题（跟随系统 / 浅色 / 深色）、编辑器字号（10–24px，默认 14px）、2/4 空格缩进、自动换行和图片面板开关；立即生效并自动保存，支持恢复默认 | — |
| 其它 | 2/4 空格缩进快捷切换、自动换行开关（`Alt+Z`）、搜索替换（`⌘F`）、拖入 `.json` 文件打开、内容自动保存 | — |

底部按钮的悬浮提示约 120 毫秒出现，也支持键盘聚焦显示。新传入或拖入的 JSON 替换当前标签内容，不会自动新增标签。重新打开插件时恢复各标签的根文档和当前选中的标签。

设置对所有标签、过滤结果和嵌套子视图统一生效。「跟随系统」在 uTools 中跟随 uTools 的亮暗模式，浏览器调试时跟随操作系统；手动选择浅色或深色后保持该选择。设置与底部的缩进、换行、图片按钮同步，按 `Esc` 或点击遮罩可关闭设置。恢复默认会重置这些偏好；缩进仍按现有规则更新当前文档的排版。

### 链接识别范围

- `http://`、`https://` 链接，以及 `//host/path` 协议相对地址（按 https 处理）
- 带 JSON 转义的链接：`https:\/\/a.com\/x.png`、`&`
- 嵌在 HTML/文本里的链接，如 `<img src='https://...png'>`；逗号分隔的多个链接会拆开
- `data:image/...;base64,...`（可预览，不可在浏览器打开）
- 图片判断依据扩展名：png / jpg / jpeg / gif / webp / svg / bmp / ico / avif / apng / jfif，兼容 `x.jpg_.webp`、`x.jpg!thumb`、`x.jpg@100w` 等 CDN 写法

### 重复图片链接的交互

同一个链接被多个字段引用时：

1. 列表中**合并为一张卡片**，徽标显示「N 处」；
2. **点击卡片**定位到第 1 处，**再次点击**依次切换到下一处（徽标变为「2/N」），循环往复；
3. 激活后卡片**自动展开引用列表**，列出每一处的字段路径和行号，可直接点选定位到某一处；
4. 编辑器里该链接的**所有出现位置同时高亮**，当前处颜色更深，方便看清分布；
5. 反过来，在编辑器里把光标放到某个图片链接上，面板会自动选中对应卡片并标出是第几处。

字段路径使用 JS 过滤框的语法（如 `this[1].background.titleImg`），引用行右侧的按钮可复制路径，粘贴到过滤框即可单独查看该字段。JSON 有语法错误时仍能提取图片，路径暂以行号代替。

### 嵌套 JSON 字符串

很多接口会把一段 JSON 序列化成字符串放进字段里，这类字符串通常很长：

1. **标签**：放在值的前面、紧跟键名（字符串再长也看得到），显示类型和成员数，如 `{ } 4 个字段`、`[ ] 3 项`；
2. **悬浮预览**：鼠标停在标签或字符串上，弹出格式化、高亮的内容，可「进入查看」或「复制格式化」；
3. **子视图**：点击标签进入，编辑器切换为这段 JSON，折叠、链接、图片、JS 过滤都可用；里面还有嵌套字符串可以继续进入。顶部路径导航（`根 › [0].text › .data`）点任一级返回；
4. **编辑后写回**：子视图里可以直接改，返回时自动压缩、转义写回原字段（原字符串带换行的保留格式化排版），父级里一次撤销即可还原。内容不合法时不会写回，可修正后再返回，或「放弃修改」；从过滤/展开结果进入的子视图是只读的；
5. **图片路径穿透**：图片列表会显示字符串内部的路径，如 `this[0].text ▸ .background.logoImg`，复制出的路径是 `JSON.parse(this[0].text).background.logoImg`，可直接粘贴到过滤框。

标签、提示都是纯视觉元素，不影响全选复制。

## 开发

```bash
pnpm install
pnpm dev          # 启动开发服务器 http://127.0.0.1:5173（浏览器中会加载示例数据）
pnpm test         # 单元测试
pnpm test:coverage
pnpm build        # 生成 dist/，即 uTools 插件目录
```

在 uTools 中测试（需先在插件市场安装「uTools 开发者工具」）：

| 方式 | 步骤 | 用途 |
| --- | --- | --- |
| 热更新调试 | `pnpm dev` 保持运行 → 开发者工具新建项目，plugin.json 选 `public/plugin.json` → 「安装（开发模式）」→「打开」 | 改代码即时生效 |
| 测构建产物 | `pnpm build` → plugin.json 选 `dist/plugin.json` → 「安装（开发模式）」→「打开」 | 验证真实运行环境（`dist/plugin.json` 不含 `development`，不依赖开发服务器） |

- 进入插件后 `⌘⌥I` / `Ctrl+Shift+I` 打开开发者工具；
- 修改 `preload.js` 后需重启插件，建议开启「退出到后台立即结束运行」；
- 示例数据：`examples/showcase.json`（中性字段、公开图片、重复引用、协议相对地址、HTML 中的图片、大整数和多层嵌套 JSON 字符串）；`showcase.jsonc` 可演示去除注释，`showcase-nested.json` 将整份示例作为字符串放入 `[{"text":"…"}]` 中。

## 目录结构

```
public/            # 原样复制到 dist/
  plugin.json      # uTools 插件配置（关键字、JSON 正则匹配、.json 文件匹配）
  preload.js       # 仅暴露受限的 readTextFile（校验扩展名、20MB 上限）
  logo.png
src/
  core/            # 纯函数，无 DOM 依赖，单元测试覆盖
    lexer.js       # 宽松 JSON（JSONC）词法分析
    parser.js      # 解析校验、错误定位、路径记录、构建值（大整数转 BigInt）
    format.js      # 格式化 / 压缩 / 转义 / 去注释 / 去转义
    urls.js        # 字符串中的链接识别与图片判断
    images.js      # 图片提取、去重分组、按位置反查
    evaluate.js    # JS 表达式过滤与序列化
    nested.js      # 嵌套 JSON 字符串识别与递归展开
    analysis.js    # 一次解析得到：校验结果、图片（含字符串内部路径）、嵌套字符串、成员数
  editor/          # CodeMirror 6 扩展：JSONC 语法、主题、链接、定位高亮
  ui/              # 底部栏、图片面板、悬浮卡片、提示
  app.js           # 串联编辑器、分析、图片定位、工具栏动作、持久化
  app/views.js     # 视图控制器：JS 过滤 / 展开嵌套（只读结果）、嵌套子视图栈与写回
  main.js          # 入口，处理 uTools 进入事件
tests/             # vitest 单元测试
```

## 说明

- 普通点击链接只移动光标（保证可编辑），打开链接需按住 `⌘`（Windows/Linux 为 `Ctrl`）或使用悬浮卡片按钮；只允许打开 http/https 链接。
- JSON 内容只会被解析、不会被执行；过滤框中的表达式是你自己输入的 JS，会在插件内执行。
- 每个标签的根文档通过 `utools.dbStorage` 单独保存，单个标签内容序列化后超过 800KB 时不保存并会提示（uTools 单文档上限 1MB）。子视图的修改返回写回后才保存；撤销历史、折叠和视图状态只在本次运行期间保留。
- 过滤表达式中，超出安全范围的整数是 BigInt（保证精度），与普通数字运算时需先 `Number(x)` 转换。
- 图片以 `referrerpolicy="no-referrer"` 加载，避免部分 CDN 的防盗链拦截。
